# Detection of AI-Generated Arabic Text: A Data Mining Approach

**Course:** MSIS822 – Advanced Data Analytics  
**Project:** Final Project  
**Status:** Phase 1 and Phase 2 Completed

## Project Overview

This project aims to investigate differences between human-written and AI-generated Arabic academic abstracts using data mining and natural language processing techniques.

The project follows a step-by-step workflow covering dataset understanding, Arabic text preprocessing, exploratory data analysis, and subsequent machine learning experiments.

## Dataset

**Source:** [KFUPM-JRCAI/arabic-generated-abstracts](https://huggingface.co/datasets/KFUPM-JRCAI/arabic-generated-abstracts)

The dataset contains Arabic academic abstracts written by humans and generated by several AI models.

The working dataset contains:

- 8,388 human-written abstracts
- 33,552 AI-generated abstracts
- 41,940 total text records

The class distribution is approximately 20% human-written and 80% AI-generated.

## Phase 1 – Data Understanding

The initial phase focused on understanding the dataset and preparing the project structure.

Completed activities:

- Loading the dataset from Hugging Face.
- Exploring the available data subsets.
- Inspecting the dataset structure and sample records.
- Checking missing values, empty texts, and duplicate records.
- Identifying the target classes and their distribution.

## Phase 2 – Data Preprocessing and Exploratory Data Analysis

The second phase focused on preparing Arabic text and investigating linguistic patterns.

**Arabic Text Preprocessing**
- Arabic character normalization.
- Diacritic and tatweel removal.
- Removal of non-Arabic characters.
- Arabic stopword removal.
- Arabic stemming using the ISRI stemmer.

**Exploratory Data Analysis**
- Class distribution visualization.
- Word count and average word length analysis.
- Sentence length analysis.
- Type-token ratio and other lexical statistics.
- Arabic word cloud generation.
- Unigram, bigram, and trigram frequency analysis.
- Initial comparison between human-written and AI-generated texts.

### Initial Observations

The exploratory analysis showed differences in average text length, lexical statistics, and frequently occurring academic expressions.

Human-written texts contained approximately 118.58 words on average, compared with 101.01 words for AI-generated texts.

These observations are descriptive and do not, by themselves, establish classification performance.

## How to Run

Install the required Python packages:

```bash
pip install -r requirements.txt
```

Run the data processing and EDA pipeline:

```bash
python run_pipeline.py --arabic-font "C:\Windows\Fonts\arial.ttf"
```

The dataset is retrieved from Hugging Face during execution. Raw and processed datasets are excluded from Git tracking.
